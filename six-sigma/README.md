# Six Sigma Quality Dashboard

A Tableau Public dashboard tracking DPMO, sigma level, and first-pass yield
across simulated inspection sessions, built from the trained
Industrial Surface Defect Detector model.

**Live dashboard:** https://public.tableau.com/app/profile/trenton.bolinger/viz/SteelDefectDetectorSixSigmaDashboard/SixSigmaQualityDashboard

## Files

- `batch_quality_report.py`: runs the trained ResNet-18 model against real
  validation images, simulates 10 inspection sessions, and computes
  quality metrics per session.
- `six_sigma_sessions.csv`: output of the script above. Source data for
  the Tableau dashboard.

## Methodology

The live demo app (`demo.py`) already computes DPMO, sigma level, and
first-pass yield for a single session as a user submits images through
the Gradio interface. That live feature has no persistent history across
sessions, so there was no existing dataset showing these metrics trending
over time.

To generate real trend data instead of fabricating numbers, this script
runs the same trained model and the same confidence-threshold logic
(85% minimum confidence, otherwise rejected) used in the live demo,
against the project's real labeled validation images.

**Sampling note:** the underlying dataset was built class-balanced for
model training (240 images per class across 8 classes), which does not
reflect a realistic production defect rate. Sampling directly from that
balanced set would produce an unrealistic ~75% defect rate per session.
To simulate a realistic production run, each session instead draws a
randomly varying 85-96% of its images from the `good_steel` class, with
the remainder split between real defect images (across all 6 defect
types) and `unknown` images. Every prediction is still generated by
running an actual image through the actual trained model; only the mix
of which images go into each simulated session was adjusted to reflect
realistic defect prevalence rather than the dataset's training-balanced
composition.

## What Each Chart Shows

- **DPMO Trend**: defects per million opportunities per session, using
  only the 6 true defect classes (`good_steel` and `unknown` excluded,
  consistent with the live demo's calculation).
- **First-Pass Yield Trend**: percentage of images classified as
  `good_steel` per session.
- **Sigma Level Trend**: DPMO converted to a Six Sigma level using the
  standard conversion table, matching the live demo's lookup logic.

## How to Reproduce

    cd aerospace-defect-detector
    python3 six-sigma/batch_quality_report.py
